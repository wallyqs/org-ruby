#+TITLE:   Releasing a new version of the gem
#+runmode: idempotent

- Bump the current version

#+begin_src ruby :tangle lib/org-ruby/version.rb
module OrgRuby
  VERSION = '0.9.12'
end
#+end_src

- Create the gem

#+name: build-the-gem
#+begin_src sh
gem build org-ruby.gemspec
#+end_src

- Make sure CI is green on GitHub Actions (see =.github/workflows/ci.yml=),
  which runs the specs on each supported Ruby with and without
  CodeRay/Pygments. Locally the same matrix can be run with:

#+begin_src sh
bundle exec rake test
#+end_src
